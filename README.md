# BugsCollector

**A collection of real-world bugs, root-cause analyses, code fixes, and technical case studies.**

BugsCollector is a public repository where I document bugs discovered while developing and maintaining software applications.

Each case study focuses on understanding the underlying problem, identifying its root cause, implementing a solution, and verifying the results.

## Objectives

* Document real-world software bugs.
* Explain technical problems and their root causes.
* Share code changes and debugging techniques.
* Include screenshots and other technical evidence.
* Demonstrate how fixes are tested and verified.
* Build a portfolio of practical software engineering experience.

## Case Study Format

Each documented bug may include:

1. **Problem:** What was happening?
2. **Diagnosis:** What caused the problem?
3. **Solution:** What code changes fixed it?
4. **Verification:** How was the fix tested?
5. **Evidence:** Screenshots, logs, test results, or code diffs.
6. **Technology:** The languages, frameworks, and tools involved.

## Technologies

Case studies may cover technologies such as:

* JavaScript and TypeScript
* Python and FastAPI
* React and Node.js
* REST APIs
* Databases
* Data validation
* Frontend rendering
* Backend error handling
* Automated testing

The technologies listed depend on the projects documented in this repository.

## Purpose

This repository serves as a technical knowledge base and a portfolio of debugging and problem-solving experience.

The goal is not only to show that a bug was fixed, but also to explain why it happened, how the solution works, and how the result was verified.
